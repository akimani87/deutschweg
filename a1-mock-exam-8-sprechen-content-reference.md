## Teil 2 — Persönliche Fragen zu einem Thema

Six keyword topic cards in the travel register, each with 3-4 natural
follow-up questions:

1. **Urlaub** — Wohin fahren Sie gern im Urlaub? Wie oft machen Sie
   Urlaub? Fahren Sie lieber ans Meer oder in die Berge?
2. **Hotel** — Wohnen Sie im Urlaub lieber im Hotel oder in einer
   Ferienwohnung? Was ist Ihnen im Hotel wichtig? Frühstücken Sie im
   Hotel?
3. **Reisen** — Reisen Sie gern mit dem Zug, dem Bus oder dem Auto?
   Wie lange dauert Ihre längste Reise? Reisen Sie lieber allein oder
   mit der Familie?
4. **Zug/Bus** — Fahren Sie oft mit dem Zug? Kaufen Sie die Fahrkarte
   online oder am Bahnhof? Sind Sie schon mal zu spät zum Zug
   gekommen?
5. **Gepäck** — Wie viele Koffer nehmen Sie mit in den Urlaub? Was ist
   immer in Ihrem Koffer? Haben Sie schon mal Ihr Gepäck verloren?
6. **Wetter** — Wie ist das Wetter, wenn Sie in Urlaub fahren? Schauen
   Sie vor der Reise die Wettervorhersage an? Was machen Sie bei
   Regen im Urlaub?

## Teil 3 — Bitten formulieren und darauf reagieren

Six request/action cards, mirroring the format
[a1-mock-exam-3-sprechen-content-pending.md](a1-mock-exam-3-sprechen-content-pending.md)
and
[a1-mock-exam-7-sprechen-content-reference.md](a1-mock-exam-7-sprechen-content-reference.md)
used for their own Teil 3 cards:

1. **Zimmer zeigen** — Können Sie mir bitte das Zimmer zeigen? / Zeigen
   Sie mir bitte das Zimmer.
2. **Koffer tragen** — Können Sie mir bitte mit dem Koffer helfen? /
   Tragen Sie bitte den Koffer — negative Reaktion: "Tut mir leid, ich
   habe selbst viel Gepäck."
3. **Fenster öffnen** — Öffnen Sie bitte das Fenster. / Können Sie
   bitte das Fenster öffnen? Es ist warm hier.
4. **Karte zeigen** — Können Sie mir das auf der Karte zeigen? / Zeigen
   Sie mir bitte, wo wir sind.
5. **Taxi rufen** — Können Sie bitte ein Taxi rufen? / Rufen Sie mir
   bitte ein Taxi.
6. **Tür öffnen** — Öffnen Sie bitte die Tür. / Können Sie mir die Tür
   aufhalten?
